DECIDED: Metadata uses server R2 uploaded time for age safety and labels it Uploaded, with local absolute date + relative age. Original file creation time is unknown for legacy uploads. DECIDED: Common filters: text search, type, age (7/30/90 days, older-than 90 preset), date range, sorting. Literal default with explicit regex switch; RE2JS or another actually verified linear-time engine in a cancellable browser Web Worker. Rank by match count then upload time/ID, display snippets, invalid-pattern state, and content coverage/truncation honestly. No universal binary fulltext claim. No private index persistence in localStorage.

DECIDED: Simplify delete review. UI freezes explicit ID/version refs from the complete observed filtered set, shows exact count, bytes, cutoff and names, and requires explicit confirmation. Commit bounded batches (e.g. 100 IDs) to one authenticated bulk-delete route with per-ID deleted/missing/changed/failed outcomes and expected versions. Never recompute an age predicate after confirmation. Cross-page selection is global; partial corpus cannot silently become select-all. A broad durable multi-route review-job framework is unnecessary for this personal catalog; no persistent review database is required. Storage module exposes version-aware remove. UI preserves unprocessed/failed refs and clearly reports partial success.

DECIDED: Native image/PDF/audio/video previews, safe self-hosted Markdown and escaped text/code/data views, bounded JSON/CSV/TSV, DOCX text/semantic preview if bounded decompression can be verified. XLSX/PPTX/legacy Office/archives/unsupported files keep clean fallback unless a bounded safe preview is actually proved. Never upload files to third-party conversion services.
